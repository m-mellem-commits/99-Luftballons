# 99 Luftballons

**Oleas Deutsch-Universum.** Et magasin for tysk på videregående.

Siden har tre deler:

1. **Tipps:** tysk musikk, serier, filmer og bøker
2. **Deutschland:** kart over de 16 delstatene, byer, kultur, ord og slang
3. **Lernen:** grammatikk, rundt 100 verb med øvemodus, og huskeregler

Alt ligger i én fil, `index.html`. Åpne den i en nettleser, eller slå på GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root). Da blir siden tilgjengelig på `https://m-mellem-commits.github.io/99-Luftballons/`.

Kartgrunnlag: delstatsgrenser fra [deutschlandGeoJSON](https://github.com/isellsoap/deutschlandGeoJSON).
